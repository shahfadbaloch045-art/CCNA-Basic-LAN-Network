**CCNA Project 01: Basic LAN Network**

**Project Overview**

My first beginner-level networking project, designed using Cisco Packet Tracer.

**Devices Used**

- 1 Cisco 2960 Switch
- 2 PCs
- 2 Copper Straight-Through Cables

**IP Addressing**

**Device| IP Address| Subnet Mask**
    PC0| 192.168.1.1| 255.255.255.0
    PC1| 192.168.1.2| 255.255.255.0

**Network Configuration**

Both PCs were configured with static IPv4 addresses and connected through a Cisco switch.

**Testing**

Used the ping command to test connectivity between PC0 and PC1.

"ping 192.168.1.2"

**Result:** Successful communication between both PCs.

**Concepts Learned**

- LAN Networking
- Star Topology
- Cisco Switching
- IPv4 Addressing
- Subnet Mask
- Ping Testing

**Software**

Cisco Packet Tracer
